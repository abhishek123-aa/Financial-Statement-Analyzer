# Company Financial Statement Analyzer

## 📊 Project Overview
This project analyzes a company's financial performance using basic accounting ratios.  
It uses data from the Balance Sheet and Income Statement to calculate:
- Profitability Ratios
- Liquidity Ratios
- Solvency Ratios

## 🧾 Tools Used
- Microsoft Excel (or Google Sheets)

## 📈 Key Insights
- Improved profitability and liquidity in Year 2
- Stable solvency position
- Suitable for BBA/Finance students learning ratio analysis

## 📂 File Structure
- `Company_Financial_Statement_Analyzer.xlsx` — Financial data and ratio analysis
- `README.md` — Project description
